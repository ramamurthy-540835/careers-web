# Trusted Web Activity

Run `bubblewrap doctor`, then `bubblewrap init --manifest https://<domain>/manifest.webmanifest` and `bubblewrap build`.

Generate asset links with `TWA_PACKAGE_NAME` and `TWA_SHA256_FINGERPRINT`. In Play Console set privacy policy to `https://<domain>/privacy`, complete Data safety from the application data model, rating, required target API level, and store listing.
